# MuJoCo Mojo

This project uses MuJoCo Mojo. Before writing Mojo code, read the docs that ship with the installed version. `mujoco-mojo docs path` prints the folder they are in, and the paths below are from it.

- Start with `docs/user-guides/workflow/getting-started.md`.
- Every command and option is in `docs/reference/cli.md`.
- Run the campaign with `bash run.sh` and open the interactive viewer with `bash reloaded.sh`.
- Do not guess Mojo names: read the guide, or the source of the installed package.
