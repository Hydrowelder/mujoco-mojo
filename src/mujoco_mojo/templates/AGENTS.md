# MuJoCo Mojo

This project uses MuJoCo Mojo. Before writing Mojo code, read the guides that ship with the installed version. `mujoco-mojo docs path` prints the folder they are in.

- Start with `workflow/getting-started.md`.
- Every command and option is in `reference/cli.md`.
- Run the campaign with `bash run.sh` and open the interactive viewer with `bash reloaded.sh`.
- Do not guess Mojo names: read the guide, or the source of the installed package.
